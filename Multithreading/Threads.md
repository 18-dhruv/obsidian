


## Processes - An operating system uses processes to seperate the application that are being executed.


- ## Threads 
    A thread is a basic unit to which an operating system allocates processor time. Each thread has a scheduling priority and maintain a set of structures the system uses to save the thread context includes all the information the thread need seamlessly resume execution, including the thread's set of CPU Registers and stack

- ## Race condition
     A Race condition is a bug that occurs when the outcomes of a program depends on which of two or more threads reaches a particular blocks of code first. Running the program many times produces different results, and the results of any given run cannot be predicted
