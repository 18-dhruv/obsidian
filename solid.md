
# S ( single responsible principle)
A class should only have one reason to change
# O (open and close principle) 
classes should be open for extention but close for modification 
means we can add to exiting behaviour without editing code (Virtual and override helps us in this )
# L (liskov substitution principle)
subclass should be used anywhere base class is expected whitout breaking anything
# I (Interface segregation principle)
Don't force a class to implement methods it don't need - prefer many small, specific interface over  one large , general one 
# D (dependency inversion principle)
